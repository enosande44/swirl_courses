# Programmation R en français

Ce cours est une première version française destinée aux débutants. Il couvre les bases de R, l’organisation des fichiers, les vecteurs, les fonctions et l’inspection des données.

Les commandes et les noms d’objets restent en syntaxe R. Les consignes, explications, indices et choix de réponse sont en français.

## Installation locale

Depuis une session R :

```r
library(swirl)
install_course_directory("C:/chemin/vers/swirl_courses/R_Programming_FR")
swirl()
```

Choisissez **Programmation R en français**.

## Installation depuis GitHub

Après avoir publié ce dossier dans votre fork :

```r
library(swirl)
install_course_github("VOTRE_COMPTE", "VOTRE_DEPOT", "R_Programming_FR")
swirl()
```

Le cours est séparé de `R_Programming` afin de ne pas modifier les leçons anglaises existantes.
